# LuCI для ByeDPI

Веб-интерфейс управления ByeDPI для OpenWrt 24.10 и 25.12.
Позволяет управлять сервисом, менять его настройки через формы и редактировать
конфигурационный файл прямо в LuCI.

## Установка и обновление

Выполните в консоли роутера от root:

```sh
sh <(wget -q -O - https://raw.githubusercontent.com/qb60/luci-app-byedpi/main/install.sh)
```

Если ByeDPI ещё не установлен, установщик предложит установить его из
[ByeDPI-OpenWrt](https://github.com/DPITrickster/ByeDPI-OpenWrt).
Введите `y` для подтверждения или нажмите Enter для отмены.

Если ByeDPI уже установлен и доступна новая версия, установщик предложит
обновить его. При отказе или нажатии Enter обновление ByeDPI будет пропущено,
а установка интерфейса продолжится. Существующие настройки сохраняются.

Для обновления повторно выполните ту же команду.

## Возможности

После установки откройте **Services → ByeDPI** в LuCI.

### Service

- Версия ByeDPI, состояние сервиса, адрес и порт прокси.
- Кнопки **Start**, **Stop** и **Restart**.
- Переключатель **Start on boot** для запуска при загрузке роутера.
- Автоматическое обновление состояния каждые 5 секунд.

### Settings

- Основные настройки сервиса и параметры командной строки.
- Дополнительные параметры в сворачиваемой группе **Advanced Settings**.
- Редактор исходного файла конфигурации — **Edit configuration file**.

Если поле **Custom command-line options** заполнено, отдельные параметры
ниже него не используются и недоступны для редактирования. Очистите поле,
чтобы снова настраивать сервис через форму. Сохранённые значения при этом
не удаляются.

## Сохранение настроек

- **Save** — сохранить изменения без применения.
- **Save & Apply** — сохранить и применить изменения.
- **Reset** — сбросить несохранённые изменения формы.

После редактирования исходного файла нажмите **Save**, затем **Restart**
на вкладке Service, чтобы применить изменения. **Cancel** закрывает редактор
без сохранения. Ошибочный файл не заменит рабочую конфигурацию.

Если вы только что установили ByeDPI, настройте его во вкладке Settings
и запустите кнопкой **Start**. При необходимости включите **Start on boot**.
Этот переключатель управляет автозапуском при загрузке роутера, а
**Enable this configuration** — использованием выбранной конфигурации.

После обновления ByeDPI нажмите **Restart** на вкладке Service,
чтобы сервис использовал новую версию.

## Удаление

Выполните нужные команды в консоли роутера от root.

### Только веб-интерфейс

ByeDPI продолжит работать без LuCI-интерфейса.

OpenWrt 24.10:

```sh
opkg remove luci-app-byedpi
```

OpenWrt 25.12:

```sh
apk del luci-app-byedpi
```

### Веб-интерфейс и ByeDPI

Сначала остановите сервис и отключите его автозапуск:

```sh
/etc/init.d/byedpi stop
/etc/init.d/byedpi disable
```

Затем удалите оба пакета.

OpenWrt 24.10:

```sh
opkg remove luci-app-byedpi byedpi
```

OpenWrt 25.12:

```sh
apk del luci-app-byedpi byedpi
```
